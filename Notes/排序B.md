# 排序算法笔记（进阶）：归并、快排、桶排、堆排、基数排序

> 默认升序排序。这些排序大多比前三种快，实际复杂度更优。

---

## 一、归并排序（Merge Sort）【4-5】

### 1. 核心思想
**分治法**：把数组不断二分，直到每个子数组只剩 1 个元素；再两两合并，合并时保证有序。

- 分：`mid = (l + r) / 2`，递归排左半、右半；
- 治：把两个有序子数组合并成一个有序数组。

### 2. 步骤
1. 若区间长度 ≤ 1，直接返回；
2. 取中点，递归排序左半、右半；
3. 用临时数组，双指针合并两个有序区间；
4. 把临时数组写回原数组。

### 3. 代码示例
```cpp
void mergeSort(int a[], int l, int r, int tmp[]) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(a, l, mid, tmp);
    mergeSort(a, mid + 1, r, tmp);

    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++]; // <= 保证稳定
        else              tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r)   tmp[k++] = a[j++];

    for (int p = l; p <= r; p++) a[p] = tmp[p];
}
```

### 4. 例子
`[5, 2, 9, 1, 3]`

- 分：`[5,2]`、`[9,1,3]` → 继续分到单元素
- 合：`[5],[2]` → `[2,5]`；`[9],[1]` → `[1,9]`；`[1,9],[3]` → `[1,3,9]`
- 合：`[2,5],[1,3,9]` → `[1,2,3,5,9]`

### 5. 特点
- 时间复杂度：最好、最坏、平均都是 `O(n log n)`
- 空间复杂度：`O(n)`（需要临时数组）
- 稳定性：**稳定**
- 优点：稳定，复杂度稳定，适合链表排序、外部排序
- 缺点：需要额外空间

## 二、快速排序（Quick Sort）【4-5】

### 1. 核心思想
**分治法**：选一个基准值 `pivot`，把数组分成两部分——左边都 ≤ pivot，右边都 ≥ pivot，再递归排序左右两部分。

### 2. 步骤
1. 选基准（常选第一个 / 最后一个 / 随机 / 三数取中）；
2. 双指针划分：把小的放左、大的放右；
3. 基准归位；
4. 递归左右子区间。

### 3. 代码示例（以最左为基准）
```cpp
void quickSort(int a[], int l, int r) {
    if (l >= r) return;

    int pivot = a[l];
    int i = l, j = r;
    while (i < j) {
        while (i < j && a[j] >= pivot) j--; // 从右找小于基准
        while (i < j && a[i] <= pivot) i++; // 从左找大于基准
        if (i < j) swap(a[i], a[j]);
    }
    swap(a[l], a[i]); // 基准归位

    quickSort(a, l, i - 1);
    quickSort(a, i + 1, r);
}
```

### 4. 例子
`[5, 2, 9, 1, 3]`，基准 5：

- 右边找小于 5：3；左边找大于 5：9 → 交换 → `[5,2,3,1,9]`
- 继续：右边到 1，左边到 5，i 和 j 相遇
- 基准归位 → `[1,2,3,5,9]`
- 递归左右：左边已有序，右边单元素

### 5. 特点
- 时间复杂度：平均 `O(n log n)`，最坏 `O(n²)`（已有序 + 选端点作基准）
- 空间复杂度：`O(log n)`（递归栈）
- 稳定性：**不稳定**
- 优化：
  - 随机基准 / 三数取中，避免最坏情况；
  - 小区间用插入排序；
  - 三路划分处理大量重复元素。
- 实际应用：**C++ `std::sort` 的核心是 introsort（快排 + 堆排 + 插入排序）**

## 三、桶排序（Bucket Sort）【4】

### 1. 核心思想
把数据按范围分到若干个“桶”里，每个桶内部单独排序，最后按桶顺序拼接。

前提：数据分布较均匀，且知道数据范围。

### 2. 步骤
1. 确定数据范围 `[min, max]`；
2. 划分 k 个桶，映射函数：`bucket = (x - min) * k / (max - min + 1)`；
3. 把元素放入对应桶；
4. 每个桶内部排序（可用插入排序 / `sort`）；
5. 按桶顺序合并。

### 3. 代码示例
```cpp
void bucketSort(vector<int>& a, int k) {
    if (a.empty()) return;
    int mn = *min_element(a.begin(), a.end());
    int mx = *max_element(a.begin(), a.end());
    if (mn == mx) return;

    vector<vector<int>> buckets(k);
    for (int x : a) {
        int idx = (int)((long long)(x - mn) * k / (mx - mn + 1));
        if (idx >= k) idx = k - 1;
        buckets[idx].push_back(x);
    }

    int p = 0;
    for (auto& b : buckets) {
        sort(b.begin(), b.end()); // 桶内排序
        for (int x : b) a[p++] = x;
    }
}
```

### 4. 例子
`[29, 25, 3, 49, 9, 37, 21]`，范围 0~49，分 5 个桶（每桶 10 个数）：

- 桶 0（0~9）：3, 9
- 桶 2（20~29）：29, 25, 21
- 桶 3（30~39）：37
- 桶 4（40~49）：49

桶内排序后拼接：`[3,9,21,25,29,37,49]`

### 5. 特点
- 时间复杂度：平均 `O(n + k)`，最坏 `O(n²)`（数据全落一个桶）
- 空间复杂度：`O(n + k)`
- 稳定性：**取决于桶内排序**；桶内用稳定排序则整体稳定
- 优点：数据均匀时接近线性
- 缺点：依赖分布，需要额外空间
- 适用：数据范围已知、分布均匀

## 四、堆排序（Heap Sort）【4】

### 1. 核心思想
利用**大顶堆**（升序排序用大顶堆）：
1. 建堆：把数组调整成大顶堆；
2. 反复把堆顶（最大值）与末尾交换，堆大小减 1，再向下调整。

### 2. 前置知识：堆的下标关系
对下标 `i`（从 0 开始）：
- 左孩子：`2*i + 1`
- 右孩子：`2*i + 2`
- 父节点：`(i - 1) / 2`

### 3. 步骤
1. 从最后一个非叶子节点 `n/2 - 1` 开始，依次向下调整，建大顶堆；
2. 把堆顶与末尾交换；
3. 堆大小减 1，对新堆顶向下调整；
4. 重复直到堆大小为 1。

### 4. 代码示例
```cpp
void heapify(int a[], int n, int i) {
    int largest = i;
    int l = 2 * i + 1;
    int r = 2 * i + 2;

    if (l < n && a[l] > a[largest]) largest = l;
    if (r < n && a[r] > a[largest]) largest = r;

    if (largest != i) {
        swap(a[i], a[largest]);
        heapify(a, n, largest);
    }
}

void heapSort(int a[], int n) {
    // 建堆
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(a, n, i);

    // 逐个取最大值放到末尾
    for (int i = n - 1; i > 0; i--) {
        swap(a[0], a[i]);
        heapify(a, i, 0);
    }
}
```

### 5. 例子
`[5, 2, 9, 1, 3]`

- 建大顶堆：`[9,3,5,1,2]`
- 9 与末尾 2 交换：`[2,3,5,1,9]`，调整堆 → `[5,3,2,1,9]`
- 5 与 1 交换：`[1,3,2,5,9]`，调整 → `[3,1,2,5,9]`
- 3 与 2 交换：`[2,1,3,5,9]`，调整 → `[2,1,3,5,9]`
- 2 与 1 交换：`[1,2,3,5,9]`

### 6. 特点
- 时间复杂度：最好、最坏、平均都是 `O(n log n)`
- 空间复杂度：`O(1)`（原地排序）
- 稳定性：**不稳定**
- 优点：原地 + 最坏也是 `O(n log n)`
- 缺点：常数较大，缓存不友好，实际常比快排慢
- 应用：`std::priority_queue`、Top-K 问题、`std::sort` 的 introsort 兜底

## 五、基数排序（Radix Sort）【4-5】

### 1. 核心思想
**按位排序**，从最低位到最高位，每一位用**稳定**的计数排序 / 桶排序处理。所有位处理完后整体有序。

### 2. 步骤
1. 找到最大数，确定最大位数 `d`；
2. 从个位开始，对每一位执行稳定排序（通常用计数排序）；
3. 依次处理十位、百位……直到最高位；
4. 结束后数组有序。

### 3. 代码示例（LSD 最低位优先，非负数）
```cpp
void radixSort(int a[], int n) {
    if (n <= 1) return;

    int mx = *max_element(a, a + n);
    int exp = 1; // 当前处理位：1, 10, 100...
    int* tmp = new int[n];
    int cnt[10];

    while (mx / exp > 0) {
        memset(cnt, 0, sizeof(cnt));

        // 统计当前位
        for (int i = 0; i < n; i++)
            cnt[(a[i] / exp) % 10]++;

        // 前缀和，确定位置
        for (int i = 1; i < 10; i++)
            cnt[i] += cnt[i - 1];

        // 从后往前放，保证稳定
        for (int i = n - 1; i >= 0; i--) {
            int d = (a[i] / exp) % 10;
            tmp[--cnt[d]] = a[i];
        }

        for (int i = 0; i < n; i++) a[i] = tmp[i];
        exp *= 10;
    }
    delete[] tmp;
}
```

### 4. 例子
`[170, 45, 75, 90, 802, 24, 2, 66]`

- 按个位：`[170,90,802,2,24,45,75,66]`
- 按十位：`[802,2,24,45,66,170,75,90]`
- 按百位：`[2,24,45,66,75,90,170,802]`

### 5. 特点
- 时间复杂度：`O(d × (n + k))`，其中 `d` 是位数，`k` 是进制（十进制 k=10）
- 空间复杂度：`O(n + k)`
- 稳定性：**稳定**（必须用稳定排序处理每一位）
- 优点：整数排序接近线性
- 缺点：只适合整数 / 定长字符串；需要额外空间；负数需特殊处理
- 适用：整数范围不大、位数不多的大数据量排序

## 六、五种排序对比总结

| 排序算法 | 核心思想 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 |
|---|---|---|---|---|---|
| 归并排序 | 分治 + 合并 | `O(n log n)` | `O(n log n)` | `O(n)` | 稳定 |
| 快速排序 | 分治 + 划分 | `O(n log n)` | `O(n²)` | `O(log n)` | 不稳定 |
| 桶排序 | 分桶 + 桶内排序 | `O(n + k)` | `O(n²)` | `O(n + k)` | 看桶内排序 |
| 堆排序 | 建堆 + 反复取堆顶 | `O(n log n)` | `O(n log n)` | `O(1)` | 不稳定 |
| 基数排序 | 按位稳定排序 | `O(d(n+k))` | `O(d(n+k))` | `O(n+k)` | 稳定 |

---

## 七、记忆口诀

- **归并**：先分后合，合并有序，稳定但费空间。
- **快排**：选基准，小的左、大的右，平均快、最坏慢。
- **桶排**：按范围分桶，桶内排序，均匀时线性。
- **堆排**：建大顶堆，最大放末尾，原地 `O(n log n)`。
- **基数**：从低位到高位，按位稳定排序。

---

## 八、易错点

1. **归并**：合并时用 `<=` 才稳定；临时数组要写回原数组。
2. **快排**：基准选端点 + 数据已有序 → 退化 `O(n²)`；比较时注意 `i < j` 边界。
3. **桶排序**：桶数量 `k` 要合理；映射函数要防止越界；数据全落一个桶会退化。
4. **堆排序**：建堆从 `n/2 - 1` 开始；交换堆顶后堆大小要减 1；下标从 0 开始时孩子是 `2i+1`、`2i+2`。
5. **基数排序**：每一位必须用**稳定**排序；负数要先分离处理或加偏移；`exp` 别溢出。
6. **稳定性总结**：
   - 稳定：归并、基数、桶（桶内稳定时）
   - 不稳定：快排、堆排

## 九、实际使用建议

| 场景 | 推荐 |
|---|---|
| 一般排序 | `std::sort`（introsort，快排为主） |
| 需要稳定 | `std::stable_sort`（归并） |
| 只要前 k 个 | `std::partial_sort` / `nth_element`（堆思想） |
| 优先队列 / Top-K | `std::priority_queue`（堆） |
| 整数范围小、量大 | 基数排序 / 桶排序 |
| 链表排序 | 归并排序 |
| 外部排序（大数据文件） | 归并排序 |

**一句话**：考试要会手写归并、快排、堆排，理解桶排和基数排序的思想；实际开发优先 `std::sort`，需要稳定就 `stable_sort`。
