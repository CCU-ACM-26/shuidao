### 一、 迭代器到底是个啥？

不要把迭代器想得很神秘。对于 `vector` 来说，**迭代器本质上就是一个“披着高级外衣的指针”**。

假设你有一个 `vector<int> v = {10, 20, 30};`，它在内存里是连续存放的：

```text
内存地址：  1000    1004    1008    1012
元素内容：  [10]    [20]    [30]   (无意义)
           ↑                        ↑
         v.begin()               v.end()
```

*   **`v.begin()`**：就是一个指向 `1000` 的指针。
*   **`v.end()`**：注意！它指向的是 `1012`，也就是**最后一个元素再后面的位置**（尾后迭代器）。它**没有真实数据**，专门用来标记“到底了”。

---

### 二、 迭代器的四大基本功（怎么用）

我们来看看迭代器是如何遍历数组的，这比范围 `for` 循环更本质：

```cpp
vector<int> v = {10, 20, 30};

// 1. 声明迭代器：类型是 vector<数据类型>::iterator
// 因为类型名太长，我们一般用 auto 自动推导
vector<int>::iterator it = v.begin(); 
// 或者：auto it = v.begin();

// 2. 循环条件：只要没走到结尾（!= v.end()），就继续
while (it != v.end()) { 
    
    // 3. 解引用：*it 就是取出当前指针指向的值
    cout << *it << endl;  
    
    // 4. 移动：++it 让指针走到下一个元素（+4 个字节）
    ++it;                 
}
```

**为什么这里写 `!= v.end()` 而不是 `< v.end()`？**
因为绝大多数容器的迭代器只支持 `!=` 和 `==`，不支持比大小（比如链表）。为了通用，标准写法永远是 `!=`。
**为什么写 `++it` 而不写 `it++`？**
在 C++ 里，`++it` 是直接加，`it++` 会先生成一个临时副本再返回，稍微浪费性能。算竞里习惯永远写 `++it`。

### 三、 为什么说范围 `for` 循环是“语法糖”？

你平时最爱写的：
```cpp
for (auto &ele : v) {
    cout << ele << endl;
}
```
编译器在底层，**完完全全**把它翻译成了上面第二部分的迭代器代码：

```cpp
for (auto it = v.begin(); it != v.end(); ++it) {
    auto &ele = *it; // 把解引用出来的值起个别名叫 ele
    cout << ele << endl;
}
```
所以，只要你懂了迭代器，范围 `for` 是怎么跑起来的你一眼就懂了；反过来，如果碰到无法用范围 `for` 的情况，你就必须切回迭代器写法。

### 四、 `vector` 迭代器的“特权”：随机访问

因为是连续内存，`vector` 的迭代器是**最强大的迭代器（随机访问迭代器）**，它能像指针一样随意跳跃：

**1. 跳跃移动：**
```cpp
auto it = v.begin();
it = it + 2;      // 直接跳到第 3 个元素（下标 2）
it += 1;          // 再往后跳 1 个
it = it - 1;      // 往前退 1 个
```

**2. 迭代器相减算距离：**
这是 `vector` 独有的大招，`set` 和 `map` 绝对做不到：
```cpp
auto it = v.begin() + 2;
int idx = it - v.begin();  // 结果就是 2。
```
**实战用法：配合二分查找**
```cpp
// lower_bound 返回的是一个迭代器，减掉 v.begin() 就能得到下标！
int pos = lower_bound(v.begin(), v.end(), 25) - v.begin();
```

### 五、 为什么迭代器会“失效”？（最容易崩的地方）

**失效**的意思是：你手里拿着的这个迭代器，突然变成了野指针，如果你再用 `*it` 去访问，程序直接崩溃（RE）。

**为什么会失效？因为 `vector` 的内部结构发生了改变。**

#### 场景 1：触发扩容（内存搬家）
```cpp
vector<int> v = {1, 2, 3};
auto it = v.begin();  // it 记住的是旧内存地址

// 塞入新元素，容量不够了！vector 会在内存中找一块更大的空地
// 把 1, 2, 3 搬过去，然后释放旧空地。
v.push_back(4);       

cout << *it;          // ❌ 崩溃！it 还指着已经被销毁的旧地址。
```
**防范：** 不要在保存了迭代器的情况下，去随意 `push_back`。

#### 场景 2：中间删除（元素前移）
```cpp
vector<int> v = {1, 2, 3, 4};
auto it = v.begin() + 1; // it 指向 2
v.erase(it);             // 删掉 2，后面的 3 和 4 会整体往前挪一格。
```
这时候，`it` 原本指向的位置确实被填上了 `3`，但是 `it` 本身的状态变得不再可靠。如果在循环里删，会导致严重的逻辑错误甚至越界。

**正确删除姿势（靠 `erase` 的返回值续命）：**
```cpp
for (auto it = v.begin(); it != v.end(); ) {
    if (*it == 2) {
        // erase 会删掉当前元素，并且【返回下一个元素的有效位置】
        it = v.erase(it); 
    } else {
        ++it; // 只有没删元素的时候，才需要手动往前走
    }
}
```

### 六、 反向迭代器（倒着走）

如果想从后往前遍历，用 `rbegin()` 和 `rend()`。

*   `v.rbegin()`：指向最后一个元素。
*   `v.rend()`：指向第一个元素的前一个位置。

```cpp
for (auto it = v.rbegin(); it != v.rend(); ++it) {
    cout << *it << " "; // 如果 v 是 1 2 3，输出就是 3 2 1
}
```
注意：对于反向迭代器，`++` 操作是往**前**走的。

---

**最后总结一下：**
迭代器就是指针的升级版。平时遍历用 `auto &ele : v`，需要找下标或移动时用 `it - v.begin()`。记住**不要在循环里乱删元素**，遇到删除必须用 `it = v.erase(it)`。
