
# 递归 (Recursion) 学习笔记

## 一、 什么是递归？
**核心定义**：函数直接或间接地调用自身。
**通俗理解**：把一个大问题，拆解成一个**与原问题逻辑相同，但规模更小**的子问题。
*   *生活例子*：查字典（查一个词，发现解释里又有生词，接着查）、电影院问排数（不知道第几排，就问前面的人）。
*   *编程思想*：**分而治之**。

## 二、 递归的两大“生死线”（缺一不可）
写递归时，脑子里必须时刻绷紧这两根弦：

1.  **递归出口（终止条件 / Base Case）**
    *   什么时候停下来？
    *   **如果不写，程序会无限调用，导致“爆栈”（Stack Overflow）崩溃。**
2.  **递推关系（递归公式 / Recursive Case）**
    *   大问题如何变成小问题？如何向出口靠近？

## 三、 经典代码模板

### 1. 基础数学递归（求阶乘）
```cpp
#include <iostream>
using namespace std;

int f(int n) {
    // 1. 递归出口
    if (n == 1) return 1; 
    
    // 2. 递推关系：f(n) = n * f(n-1)
    return n * f(n - 1); 
}

int main() {
    cout << f(5) << endl; // 输出 120
    return 0;
}
```

### 2. 算法核心：DFS 深搜模板（配合 vector 回溯）
*C组核心考点，本质是带“撤销”操作的递归。*
```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<int> path; // 记录当前路径

void dfs(int 当前状态) {
    // 1. 递归出口：到达终点
    if (到达终点) {
        输出结果;
        return;
    }
    
    // 2. 遍历当前所有可能的选择
    for (遍历所有可能的选择) {
        if (这个选择合法) {
            // 做出选择（记录现场）
            path.push_back(当前选择);
            
            // 进入下一层递归（递）
            dfs(下一步的状态);
            
            // 撤销选择（回溯，恢复现场）
            path.pop_back(); 
        }
    }
}
```

## 四、 递归的执行过程（“递”与“归”）
以 `f(3)` 求阶乘为例，计算机内部使用了**调用栈（Call Stack）**：
*   **“递”的过程（往下走）**：`f(3)` 调 `f(2)`，`f(2)` 调 `f(1)`。此时栈里压入了三层。
*   **“归”的过程（往回弹）**：`f(1)` 返回 1，`f(2)` 收到 1 算出 2，`f(3)` 收到 2 算出 6。

## 五、 新手必踩的 3 个大坑 ⚠️
1.  **忘记写递归出口**：程序死循环，直接 RE（运行错误 / 爆栈）。
2.  **忘记回溯（重置状态）**：在 DFS 中，`push_back` 了却忘记 `pop_back`，导致后面的搜索结果全错。
3.  **参数传错（值传递 vs 引用传递）**：
    *   如果在递归中修改了全局变量（如数组），回溯时一定要改回来。
    *   如果用 `vector` 传参，尽量用引用 `&` 避免拷贝浪费内存。
