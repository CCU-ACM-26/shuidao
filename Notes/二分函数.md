`lower_bound` 是 C++ 标准库 `<algorithm>` 里的一个超级好用的函数，简单来说，它就是**“封装好的二分查找”**。

在算法竞赛里，只要你的数组**排好序了**，需要找某个元素的位置，无脑用 `lower_bound` 就行，几行代码就能代替你自己手写几十行的二分。


### 一、 它的作用是啥？

`lower_bound` 的官方定义是：在指定的有序区间内，找到**第一个大于等于（\(\ge\)）**目标值的元素的位置。

**举个极其直观的例子：**
假设你有一排从小到大排好序的数字：
`v = {10, 20, 20, 30, 40}`

我们在这个数组里找不同的值，看 `lower_bound` 会返回什么：

1. 找 **`20`**：返回**第一个** `20` 的位置（下标 1）。
2. 找 **`25`**：返回第一个 \(\ge 25\) 的数，也就是 `30` 的位置（下标 3）。
3. 找 **`10`**：返回第一个 `10` 的位置（下标 0）。
4. 找 **`50`**：找不到 \(\ge 50\) 的数，返回数组的**结尾（`v.end()`）**。

---

### 二、 为什么它总是和迭代器一起出现？

这就是为什么上一问我要用 `lower_bound` 给你举例子。

`lower_bound` 的返回值**不是下标，而是一个迭代器**。
因为它不仅能用于 `vector`，还能用于 `set`、`map` 甚至普通数组。为了通用，它必须返回迭代器。

**核心公式：**
`目标下标 = lower_bound的返回值 - 容器的起始迭代器 (v.begin())`

```cpp
#include <iostream>
#include <vector>
#include <algorithm> // lower_bound 需要这个头文件
using namespace std;

int main() {
    vector<int> v = {10, 20, 20, 30, 40};
    
    // 找 >= 25 的第一个元素
    auto it = lower_bound(v.begin(), v.end(), 25);
    
    if (it != v.end()) {
        // 因为 it 是迭代器，*it 就是它指向的值（30）
        cout << "找到的值是：" << *it << endl; 
        // 迭代器相减，得到下标
        cout << "下标是：" << it - v.begin() << endl; 
    } else {
        cout << "没找到，所有元素都太小了" << endl;
    }
}
```

### 三、 它的双胞胎兄弟：`upper_bound`

有下界（lower），就有上界（upper）。
*   `lower_bound`：找第一个 **\(\ge x\)** 的位置。
*   `upper_bound`：找第一个 **\(> x\)** 的位置（严格大于）。

**再拿刚才的数组 `{10, 20, 20, 30, 40}` 举例：**

| 要找的值 | `lower_bound(x)` 返回位置 | `upper_bound(x)` 返回位置 |
| :--- | :--- | :--- |
| **20** | 下标 1（第一个20） | 下标 3（第一个30） |
| **25** | 下标 3（第一个30） | 下标 3（第一个30） |

**算竞常用套路**：如果你想知道数组里**有几个 `x`**？
只需要：`upper_bound(x) - lower_bound(x)`，直接得出 `x` 的个数！

---

### 四、 ⚠️ 必须注意的三个大坑

1.  **必须有序！必须有序！**
    如果数组没排序，`lower_bound` 跑出来的结果完全是错的。如果是乱序，必须先 `sort`，或者用 `set`。
2.  **它是二分查找，时间复杂度是 \(O(\log n)\)**。
3.  **如果是 `set` 或 `map`，千万别用 `std::lower_bound`**。
    前面讲过，对于红黑树，必须用自带的成员函数 `st.lower_bound(x)`，否则会退化成 \(O(n)\) 的暴力遍历。

**一句话总结：**
`lower_bound` 就是帮你找“在这个排好序的数组里，大于等于某个值的第一位置在哪”。返回的是迭代器，减去 `begin()` 就能变成下标。
