# 排序算法笔记：冒泡、选择、插入

> 以下默认升序排序。

---

## 一、冒泡排序（Bubble Sort）【2】

### 1. 核心思想
相邻两个元素比较，如果前一个比后一个大，就交换。每一轮把当前未排序部分的最大值“冒泡”到末尾。

### 2. 步骤
1. 从第 1 个元素开始，比较相邻两个元素；
2. 若 `a[j] > a[j+1]`，交换；
3. 一轮结束后，最大值到达末尾；
4. 重复 n-1 轮；
5. 若某一轮没有发生交换，说明已经有序，可提前结束。

### 3. 代码示例
```cpp
void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool flag = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                flag = true;
            }
        }
        if (!flag) break; // 已经有序
    }
}
```

### 4. 例子
数组：`[5, 2, 9, 1, 3]`

第一轮：
- 5 和 2 交换：`[2,5,9,1,3]`
- 5 和 9 不换
- 9 和 1 交换：`[2,5,1,9,3]`
- 9 和 3 交换：`[2,5,1,3,9]`

最大值 9 到达末尾。

### 5. 特点
- 时间复杂度：最坏 `O(n²)`，平均 `O(n²)`，最好 `O(n)`（已有序且优化）
- 空间复杂度：`O(1)`
- 稳定性：**稳定**
- 适用：教学、小规模数据

## 二、选择排序（Selection Sort）【3】

### 1. 核心思想
每一轮从未排序区间中选出最小值，放到未排序区间的第一个位置。

### 2. 步骤
1. 从第 i 个位置开始，假设它是最小值；
2. 在 `i+1` 到 `n-1` 中找更小值；
3. 找到最小值后，与第 i 个位置交换；
4. i 向后移动，重复。

### 3. 代码示例
```cpp
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[minIndex]) {
                minIndex = j;
            }
        }
        if (minIndex != i) {
            swap(a[i], a[minIndex]);
        }
    }
}
```

### 4. 例子
数组：`[5, 2, 9, 1, 3]`

- 第 1 轮：最小值 1，与 5 交换 → `[1,2,9,5,3]`
- 第 2 轮：剩余最小值 2，位置不变 → `[1,2,9,5,3]`
- 第 3 轮：剩余最小值 3，与 9 交换 → `[1,2,3,5,9]`
- 第 4 轮：剩余最小值 5，位置不变 → `[1,2,3,5,9]`

### 5. 特点
- 时间复杂度：最好、最坏、平均都是 `O(n²)`
- 空间复杂度：`O(1)`
- 稳定性：**不稳定**
- 特点：交换次数少，最多交换 `n-1` 次
- 适用：数据量小，或交换成本较高的场景

> 不稳定原因：例如 `[5a, 5b, 2]`，第一轮 2 和第一个 5 交换，可能改变相同元素的相对顺序。

## 三、插入排序（Insertion Sort）【3】

### 1. 核心思想
把数组分成“已排序区”和“未排序区”。每次取未排序区的第一个元素，插入到已排序区的合适位置。

类似打扑克牌整理手牌。

### 2. 步骤
1. 认为第 1 个元素已经有序；
2. 从第 2 个元素开始，暂存为 `key`；
3. 从已排序区末尾向前比较；
4. 比 `key` 大的元素后移；
5. 找到合适位置后插入 `key`；
6. 重复直到结束。

### 3. 代码示例
```cpp
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;

        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
}
```

### 4. 例子
数组：`[5, 2, 9, 1, 3]`

- 取 2：插入到 5 前 → `[2,5,9,1,3]`
- 取 9：放在 5 后 → `[2,5,9,1,3]`
- 取 1：插入最前 → `[1,2,5,9,3]`
- 取 3：插入到 2 后 → `[1,2,3,5,9]`

### 5. 特点
- 时间复杂度：最好 `O(n)`（已经有序），最坏 `O(n²)`，平均 `O(n²)`
- 空间复杂度：`O(1)`
- 稳定性：**稳定**
- 优点：实现简单，小规模或基本有序时效率较高
- 适用：小数据量、近乎有序的数据

---

## 四、三种排序对比总结

| 排序算法 | 核心思想 | 最好时间复杂度 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 |
|---|---|---|---|---|---|---|
| 冒泡排序 | 相邻比较交换，最大数冒泡到末尾 | `O(n)` | `O(n²)` | `O(n²)` | `O(1)` | 稳定 |
| 选择排序 | 每轮选最小值放到前面 | `O(n²)` | `O(n²)` | `O(n²)` | `O(1)` | 不稳定 |
| 插入排序 | 取元素插入已排序区 | `O(n)` | `O(n²)` | `O(n²)` | `O(1)` | 稳定 |

---

## 五、记忆口诀

- **冒泡**：相邻比较，大数后移；一轮一个最大值。
- **选择**：每轮找最小，放到最前面。
- **插入**：像摸牌，拿到一张插到合适位置。

## 六、易错点

1. 冒泡排序内层循环边界：`j < n - 1 - i`；
2. 选择排序是“找到最小值下标再交换”，不是边找边换；
3. 插入排序是“元素后移”，不是反复交换；
4. 稳定性：
   - 冒泡：稳定；
   - 选择：不稳定；
   - 插入：稳定；
5. 三种排序空间复杂度都是 `O(1)`，都是原地排序。
